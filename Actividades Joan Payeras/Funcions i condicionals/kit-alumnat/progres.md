## 📕 La meva Pokédex SCSS

Després de cada gimnàs, explica cada concepte **amb les teves paraules** en una sola línia.

- `@if / @else if / @else`: @if establece una condicion, si se cumple, ejecuta el código que posee, @else if establece una
nueva condición que se ejecuta si el anterior if es false y este es true y @else, ejecuta el código que posee siempre que 
todas las condiciones anteriores a esta sean false
- `@function` i `@return`: Una @function es un bloque de código que puede ser reutilizado y que realiza una función específica mientras que @return indica lo que ha de devolver la función
- `@warn`: Método que muestra un aviso por pantalla en caso de que suceda un error
- `@for ... through` vs `@for ... to`: El through incluye el último valor del bucle, mientras que el to no
- Interpolació `#{}`: Permite poner el valor de una variable dentro de una clase
- `math.div` i `math.percentage`: Métodos de math que, uno realiza una división, y el otro calcula un porcentage
- Mapes `( clau: valor )`:
- `@each`: Bucle que recorres una lista o mapa asignando cada valor a una variable
- `@each` imbricat: @each dentro de otro @each
- `@debug`: Muestra un valor en la terminal para así, poder ver que devuelve una función o variable
- `null` com a valor d'una propietat: Sass omite la propiedad en el css
- Diferència entre `@function` i `@mixin`: @function devuelve un valor que se asigna a una propiedad, @mixin genera bloques de código css
- `@content`: Etiqueta de @mixin que permite inyectar código
